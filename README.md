# Customer Churn Dashboard

## Objective
Analyze customer churn behavior and identify factors contributing to customer retention.

## Tools Used
- Tableau
- SQL
- Excel

## Key Insights
- Month-to-month contracts had the highest churn rate
- Customers with shorter tenure churned more frequently
- Higher monthly charges correlated with increased churn

## Recommendations
- Improve retention incentives for new customers
- Encourage longer-term contracts
